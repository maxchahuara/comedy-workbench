# Revision decisions

## Read the intention before repairing the sentence

A draft can contain several different engines: a false expectation, an observed
contradiction, an absurd rule followed consistently, a character exposing themself,
a word with two meanings, a status contest, or a precise visual misunderstanding.
Name the engine that is actually present. Do not force every joke into a pun or
every monologue into a confession.

For each important unit, record only what helps the revision:

| Field | Question |
|---|---|
| Point of view | What does this speaker want us to notice or believe? |
| Available information | What does this audience know at this moment? |
| Expected continuation | What reading does the setup make plausible? |
| Payoff | What changes that reading, status, scale, or rule? |
| Connection | Why does the surprising continuation belong to this setup? |
| Delivery dependency | Does it require a pause, a face, an image, or a sound? |
| Protected function | Which line establishes voice, emotion, context, or a later return? |

An unconnected surprise may be merely arbitrary. An accurate observation may still
have no comic turn. A deliberately predictable return can work through anticipation
and performance. These distinctions need an editorial reading, not a classifier.

## Find the level of the problem

If the premise has no tension, changing the last word will not fix it. If the
audience lacks an antecedent, add or relocate a plant. If the turn is disclosed
early, move the decisive information. If a block repeats the same thought, change
the complication or the speaker's relationship to it. If the words work but the
performance is breathless, test the reading before cutting the premise.

Preserve useful uncertainty. A joke sometimes lets the audience reach the answer
half a beat before the speaker. State that intention instead of mechanically
moving every key word to the last position.

## Alternatives and selection

Keep the original in the comparison. Make a small set of meaningfully different
options when useful: a more concrete example, a reversed status relation, a
character revealing a hidden motive, an absurd consequence, a change in scale,
or a different placement of the same revelation. These are options, not a required
sequence or a fixed quota. Do not import other writers' wording or replace an
author's dialect with a generic international register.

For each selected change, be able to complete:

> At [line/beat], I changed [specific thing] because [observed issue]. It helps
> [intention], at the cost of [voice/context/rhythm/ambiguity if relevant].

Reject an alternative if it violates the persona, depends on an unverified factual
claim, loses an important plant, or simply sounds more polished without improving
the intended effect. Keep a risky but characteristic line when its intended role
outweighs the cost. The author remains the final editor.

## What to return

For a full pass: a brief diagnosis, the performance draft, and change notes with
evidence and unresolved questions. Include alternatives only for real decisions.
For a quick punch-up: the revised line, one useful alternative if needed, and its
tradeoff. Never bury a short joke beneath a full production dossier.

When asked to adapt a draft, preserve its identity but reconsider context. A clip
cannot depend on an unseen ten-minute introduction. Expansion needs a new
complication, behavior, or consequence; explaining the existing punchline is not
development.
