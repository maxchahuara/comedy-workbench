# Jokes and compact bits

First identify whether the request is a one-liner, a short story with a turn,
topical satire, wordplay, an absurd exchange, or a compact performance bit.
One-liners need not share the shape of anecdotal jokes.

## A focused pass

Read the complete joke, then identify the point at which the listener must revise
their interpretation. Check whether the setup gives just enough information for
that revision to be possible. Remove a word only after accounting for its work:
voice, specificity, expectation, rhythm, misdirection, or later payoff.

Try moving decisive information later if the current phrasing announces the joke
too early. Read the result aloud: grammatical strain or a conspicuous synonym can
cost more than the move gains. If an explanation follows the punchline, distinguish
an explanation from a new reaction that creates another comic turn.

Additional remates (tags) should extract new consequences from the same situation.
If a tag needs a new premise and long context, it is probably another bit. Stop
before weakening the strongest ending; there is no mandatory number of tags.

## Distinct ways to revise

- Make the contradiction concrete enough to picture.
- Let the speaker unknowingly demonstrate the fault they criticize.
- Change who has power in the situation, then follow that rule consistently.
- Extend a believable detail to a disproportionate but connected consequence.
- Reinterpret a phrase only when both meanings are natural in the actual dialect.
- Build a pattern and break it where the listener expects continuation.
- Use understated behavior or a precise reaction when another sentence would spoil it.

Choose a few appropriate options; do not run every mechanism on every line.

## Topical and culturally situated material

Separate the verified event from the invented reaction. Save the supporting source
and its date when factual verification matters. Ask what the intended audience
already recognizes: an institution, a custom, a price, a public phrase. A local
reference should do comic work rather than merely swapping a city name.

Do not claim that a newly written line is globally original. If originality is
important, search distinctive wording and examine similarities manually. Lexical
search can miss paraphrases and can flag ordinary shared language.

## A useful output

Give the clean joke first, then the material alternatives and a short explanation
of the decision. If it only works with an impression, gesture, or visual prop,
state that dependency outside the spoken line. An untested candidate is labeled
as an editorial proposal, not a proven laugh.
