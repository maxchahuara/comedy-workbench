# Comedy shorts and extracted clips

Use the author's target length and medium. A short can be a direct-address joke,
a visual scene, an anecdote, a reaction, or an excerpt from a longer monologue.
Do not assume that it needs an aggressive opening, rapid cuts, or a sales ending.

## The short has its own context

Identify the minimum the viewer must understand, the expectation being built, and
the moment that pays it off. The opening image or sentence should make entry
possible. An unexplained character, an off-screen antecedent, or a pronoun pointing
to a removed section can make a good long-form joke fail as a clip.

When extracting, record the source beats and the new context line, if any. Protect
the payoff from being spoiled by a title, on-screen caption, thumbnail instruction,
or preview. A caption can serve accessibility without revealing the turn early.

## Assign work to speech and image

For a visual joke, list the state before the action, the visible change, and the
reaction. Describe a checkable contact, count, direction of attention, or readable
object when that matters. Do not write 'a hilarious moment happens'. Avoid making
the voice explain an image already doing that work unless the mismatch itself is
the joke.

Use two scripts when useful: a clean spoken script and a small visual/delivery map.
Timing columns are estimates until a reading or edit is actually measured.

| Beat | Spoken line | Visible action / information | Time assumption | Dependency |
|---|---|---|---|---|
| Establish | Minimal necessary context | Where attention should go | Reading rate | Recognizable object/persona |
| Develop | Adds a complication | Establishes the rule | Action duration | Setup remains visible or remembered |
| Pay off | Changes the reading, or stays silent | Makes the turn legible | Hold/reaction | Viewer can notice the change |

This is a planning aid, not a compulsory three-part template.

## Budget time honestly

Count spoken words separately from directions. Add explicit nonverbal actions only
when they happen sequentially; if an action overlaps speech, do not count it twice.
Include the reaction hold when it is part of the joke. Use a timed reading to
replace default word-rate assumptions. A silent visual payoff is not weak because
it has zero words.

If the clip is too long, inspect duplicated context, unnecessary explanation, and
secondary ideas before altering the acting rhythm. Preserve a slow pause when it
creates anticipation. A loop or call to action is optional and should not overwrite
the ending the author wants.

Before claiming audiovisual effectiveness, watch and listen to the actual result.
A text review, ASR transcript, or storyboard cannot establish that the image was
readable, that the pause landed, or that the delivery worked.
